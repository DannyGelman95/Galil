# Deprecated documents

These describe WorkDesk and Taskana as the two separate apps they were
before the Employee Portal. They are out of date and are kept only for
reference — do not hand them to employees or use them for a rollout.

| File | What it described | Out of date because |
|---|---|---|
| `GALIL-WorkDesk-Functional-Specification-V7.1.docx` | WorkDesk V7.1 | WorkDesk had a Tasks tab and its own sign-in; no Hebrew; no portal access |
| `GALIL-WorkDesk-Authentication-Setup-Guide.docx` | WorkDesk's Microsoft Entra sign-in | Sign-in is now one Entra application for the whole portal, set in `Employee Portal/config.js` |
| `workdesk/WorkDesk-Microsoft365-Rollout-Guide.docx` | Rolling WorkDesk out on Microsoft 365 | Same as above; WorkDesk is no longer installed on its own |
| `taskana/Taskana-Microsoft365-Rollout-Guide.docx` | Rolling Taskana out on Microsoft 365 | Taskana now signs in through the portal and takes people, clients and projects from WorkDesk |
| `workdesk/WorkDesk-the-movie.mp4` | WorkDesk demo film | Shows the old app, including the Tasks tab |
| `taskana/Taskana-the-movie.mp4` | Taskana demo film | Shows Taskana's own sign-in, people and clients, and shared saved views |

New versions — a functional specification, a Microsoft 365 rollout guide
and demo films for the Employee Portal, WorkDesk and Taskana — will be
created for the current product and placed in `docs/`. Until then, the
current reference is the Handbook (`Employee Portal/handbook/`), the
Knowledge Base (`Employee Portal/kb/`) and the administrator section of the
install guide (`Employee Portal/install/`).
