Connect the Employee Portal to GALIL's dataחיבור פורטל העובדים לנתונים של GALIL

Welcome to GALIL. Once the portal is on your device, it saves everyone's work — hours, expenses, tasks and budgets — into the company's shared GitHub repository. To let your device save there, paste the GALIL access key below, once. It takes under a minute.

ברוכים הבאים ל-GALIL. אחרי שהפורטל מותקן במכשיר, הוא שומר את העבודה של כולם — שעות, הוצאות, משימות ותקציבים — במאגר GitHub המשותף של החברה. כדי לאפשר למכשיר שלכם לשמור שם, הדביקו פעם אחת את מפתח הגישה של GALIL שמופיע למטה. זה לוקח פחות מדקה.

2. Get the GALIL access key from Danny2. קבלו את מפתח הגישה של GALIL מדני

GALIL GitHub access keyמפתח הגישה של GALIL ל-GitHub

github_pat_…

The key isn't published on this page. Ask Danny Gelman for it directly and you'll get it privately. It starts with github_pat_. Please don't forward it or post it anywhere.

המפתח לא מתפרסם בדף הזה. בקשו אותו ישירות מדני גלמן והוא יישלח אליכם באופן אישי. הוא מתחיל ב-github_pat_. נא לא להעביר אותו הלאה ולא לפרסם אותו בשום מקום.

3. Paste it into the portal3. הדביקו אותו בפורטל

  1. Open the GALIL Portal from its icon and sign in with your GALIL account.
  2. The first time you open WorkDesk or Taskana on this device, it asks for a GitHub access token.
  3. Tap the field (it reads github_pat_…) and paste the key Danny sent you.
  4. Tap Save & continue. Your work now saves to GALIL's shared repository automatically.
  1. פתחו את GALIL Portal מהסמל והיכנסו עם חשבון GALIL שלכם.
  2. בפעם הראשונה שפותחים את WorkDesk או את Taskana במכשיר הזה, המערכת מבקשת אסימון גישה של GitHub.
  3. הקישו על השדה (כתוב בו github_pat_…) והדביקו את המפתח שדני שלח לכם.
  4. הקישו שמור והמשך. מעכשיו העבודה שלכם נשמרת אוטומטית במאגר המשותף של GALIL.

Once per device. The key is stored only in this browser — it never leaves your device except to save to GALIL's repository. You only do this once on each phone or computer. If you ever get your device replaced, just paste it again.

פעם אחת לכל מכשיר. המפתח נשמר רק בדפדפן הזה — הוא לא יוצא מהמכשיר אלא כדי לשמור למאגר של GALIL. עושים את זה רק פעם אחת בכל טלפון או מחשב. אם מחליפים מכשיר, פשוט מדביקים אותו שוב.

If something goes wrongאם משהו לא עובד

If the portal says the key expired or was refused, it will ask for it again — ask Danny for the current key and paste it once more. If it still won't connect, contact the portal administrator and tell them which device and browser you're using.

אם הפורטל אומר שהמפתח פג או נדחה, הוא יבקש אותו שוב — בקשו מדני את המפתח העדכני והדביקו פעם נוספת. אם עדיין אין חיבור, פנו למנהל/ת הפורטל וציינו באיזה מכשיר ובאיזה דפדפן אתם משתמשים.
