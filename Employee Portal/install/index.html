Install the Employee Portal on your phoneהתקנת פורטל העובדים בטלפון

One app for everything: WorkDesk, Taskana, the Handbook and the Knowledge Base. It installs straight from the browser, with no app store — you get one GALIL Portal icon on your home screen that opens full screen. Sign in once inside it and every part of the portal is open to you, as your access allows. It takes about a minute.

אפליקציה אחת לכל דבר: WorkDesk,‏ Taskana, המדריך למשתמש ומאגר הידע. היא מותקנת ישירות מהדפדפן, בלי חנות אפליקציות — מקבלים סמל GALIL Portal אחד במסך הבית שנפתח במסך מלא. נכנסים פעם אחת בתוכה, וכל חלקי הפורטל פתוחים לכם לפי הגישה שלכם. זה לוקח בערך דקה.

Questionsשאלות

I don't see "Add to Home Screen" or "Install".
You're probably inside another app's built-in browser (Outlook, Teams, WhatsApp…). Tap its menu and choose Open in Safari / Open in Chrome, then try again.
Can I use the portal in Hebrew?
Yes. Tap EN / עב on the portal's home page, or in WorkDesk, Taskana, the Handbook or the Knowledge Base. The whole portal switches, right to left.
A tile on the home page says my account doesn't include it.
Your portal access is set per person. Ask an Operations Manager or the CEO to change it in WorkDesk → Management → People.
Do I need to update the app?
No. It updates itself the next time you open it with an internet connection.
The icon shows a letter or a screenshot instead of the GALIL icon.
Remove the shortcut, reload the page once in the browser, then add it again.
How do I remove it?
Touch and hold the icon, then choose Remove App (iPhone) or Uninstall / Remove (Android). On a computer, open the portal, click its ⋯ menu and choose Uninstall.
Something else isn't working?
Contact the portal administrator and tell them which phone and browser you're using.
אני לא רואה "הוסף למסך הבית" או "התקנה".
כנראה שאתם בתוך הדפדפן המובנה של אפליקציה אחרת (Outlook,‏ Teams,‏ WhatsApp…). הקישו על התפריט שלה ובחרו פתיחה ב-Safari / פתיחה ב-Chrome, ונסו שוב.

For administrators: setting up the portalלמנהלי מערכת: הקמת הפורטל

The portal is a folder of web pages — Employee Portal/ in the Galil repository — with no server of its own. It is published with the website by GitHub Pages; everything it needs is in one settings file, Employee Portal/config.js.

  1. Choose where the data lives — storage in config.js: "github" (data files on branches of a repository; each person pastes a GitHub access token once), "onedrive" (the company OneDrive; needs Microsoft Entra ID) or "local" (this browser only — the demonstration).
  2. GitHub storage — set github.owner and github.repo. WorkDesk's data goes to the workdesk-data branch and Taskana's to taskana-data; both are created on first use, and every save is a commit. Each person needs a fine-grained token with Contents: read and write on that repository.
  3. Microsoft sign-in — register one application in Microsoft Entra ID for the whole portal (a single-page application whose redirect URI is the portal's address), and put its clientId and tenantId under entra. Without them, the portal signs in with email and the demonstration password.
  4. OneDrive storage — create a WorkDesk and a Taskana folder, share each with the company (can edit), and paste the links into workdesk.folderLink and taskana.folderLink.
  5. First sign-in — the first Operations Manager or CEO signs in, checks the people in WorkDesk → Management → People, and sets the portal access of anyone who should differ from their role.
  6. Share the address — send employees this page (install/) so they can put the portal on their phones.

Per browser, Connection settings… on the sign-in screen can override config.js for testing. The guides in docs/ cover the full Microsoft 365 rollout.

הפורטל הוא תיקייה של דפי אינטרנט — Employee Portal/ במאגר Galil — בלי שרת משלו. הוא מתפרסם יחד עם האתר דרך GitHub Pages; כל מה שהוא צריך נמצא בקובץ הגדרות אחד, Employee Portal/config.js.

  1. בחרו היכן יישמרו הנתונים — storage ב-config.js: "github" (קובצי נתונים בענפים של מאגר; כל אדם מדביק אסימון גישה של GitHub פעם אחת), "onedrive" (ה-OneDrive של החברה; מחייב Microsoft Entra ID) או "local" (רק בדפדפן הזה — להדגמה).
  2. אחסון ב-GitHub — קבעו github.owner ו-github.repo. הנתונים של WorkDesk נשמרים בענף workdesk-data ושל Taskana ב-taskana-data; שניהם נוצרים בשימוש הראשון, וכל שמירה היא commit. כל אדם צריך אסימון fine-grained עם Contents: read and write על המאגר הזה.
  3. כניסה עם Microsoft — רשמו יישום אחד ב-Microsoft Entra ID לכל הפורטל (יישום חד־עמודי שכתובת ההפניה שלו היא כתובת הפורטל), והכניסו את ה-clientId וה-tenantId שלו תחת entra. בלעדיהם, הפורטל נכנס עם דוא״ל וסיסמת ההדגמה.
  4. אחסון ב-OneDrive — צרו תיקיית WorkDesk ותיקיית Taskana, שתפו כל אחת עם החברה (עם הרשאת עריכה), והדביקו את הקישורים ב-workdesk.folderLink וב-taskana.folderLink.
  5. כניסה ראשונה — מנהל/ת התפעול או המנכ"ל הראשונים נכנסים, בודקים את האנשים ב-WorkDesk ← ניהול ← אנשים, וקובעים גישה לפורטל לכל מי שצריך גישה שונה מהתפקיד שלו.
  6. שתפו את הכתובת — שלחו לעובדים את הדף הזה (install/) כדי שיתקינו את הפורטל בטלפון.

בכל דפדפן, הגדרות חיבור… במסך הכניסה יכולות לעקוף את config.js לצורכי בדיקה. המדריכים בתיקייה docs/ מכסים את ההטמעה המלאה ב-Microsoft 365.
